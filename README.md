# Centro de Treinamento Zanchettin 🥊

Landing page de alta conversão para o **Centro de Treinamento Zanchettin** (Chapecó - SC), especializada em Musculação Pesada Biomecânica, Muay Thai Tradicional, Boxe Clássico e MMA.

## 📌 Funcionalidades & Arquitetura
* **Dual-Atmosphere**: Hero Fold escura com fade cinematográfico autêntico (`from-black via-black/85 via-45% to-transparent`) e seções de valor em Light Mode (`bg-zinc-50`).
* **Geometria & Design System**: CTAs em formato de pílula (`rounded-full`), cards e tabelas de planos em formato sóbrio (`rounded-lg`).
* **Zero AI-Slop**: Tipografia sóbria sem contornos de pílulas neon ou elementos artificiais.
* **Funil de Conversão**: Roteamento direto de todos os planos e agendamentos para o WhatsApp com mensagens personalizadas.
* **SEO & Local Authority**: Schema.org `ExerciseGym` com endereço, horários de funcionamento e avaliação Google 5.0 ★ (93 reviews).

## 🚀 Tecnologias
* React 18 + TypeScript + Vite
* Tailwind CSS
* GSAP + Lenis Smooth Scroll
* Lucide Icons
